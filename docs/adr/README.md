# Architecture Decision Records

Major architecture choices are recorded here only after review and explicit
human approval. Draft comparisons may live under `docs/decisions/` until an
option is approved.

Use sequential identifiers:

```text
0001-short-decision-title.md
0002-next-decision-title.md
```

Every ADR records status, context, decision, alternatives, consequences,
security/authorization impact, data/migration impact, operational impact,
validation, and rollback/revisit triggers.
